# Incomplete Calculator
I was asked to make a complete app, so I present to you the calculator that is completely functional,
yet not quite completely sane. This calculator is perfect at calculating, but it's really shy and therefore
horrible at its job. It's best if you try out the project before watching the provided video in this case.

I hope this gets a laugh out of you at the very least, and I made the equals button massive
and orange so it looks very clickable and obvious. I have a habit of turning prompts on their head.

## Prereqs
You'll need C# (dotnet) 10 installed to compile the application, and you must either use Windows or a Virtual
Machine, as this is a WinForms app.

It should be as simple as `dotnet run` in the repo directory after that.
